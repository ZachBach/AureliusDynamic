# tsl-lib Conventions

The API contract for every node in the library. PRs are reviewed against this
document; the Definition of Done lives in [../BACKLOG.md](../BACKLOG.md) §0.

## three.js pin

- **Revision: r178**, the build embedded in the landing bundle's manifest
  (uuids `7c31e1a2-5a8e-4a2b-9f3d-0e6c8b2d4f10` = `three.core.min.js`,
  `b58f0e77-2d19-4c85-a7d3-9c41e6f2ab34` = `three.webgpu.min.js`).
- The library targets exactly this build. `tools/extract.py --assets`
  regenerates `bench/vendor/` from the bundle — vendor files are never
  committed and never sourced from anywhere else.
- Upgrading three.js is a deliberate backlog item, never a side effect. An
  upgrade PR re-runs `bench/verify-all` and re-validates every registry entry.
- The import surface is audited: `docs/tsl-exports.json` (generated by the
  bench runner) lists every symbol `THREE.TSL` actually exports at runtime,
  plus the runtime `THREE.REVISION`. A node may only import symbols present
  in that file.

## Module format

- ES modules, one node per file, under `src/<family>/<name>.js`.
- In the bench, three.js is imported from `./vendor/three.webgpu.min.js`
  (its relative `./three.core.min.js` import resolves naturally when both
  files sit in the same directory).
- Library modules never import three.js themselves — they receive the TSL
  namespace. Every node factory takes it as its first argument:

  ```js
  export const fresnel = (TSL, { power = 3, bias = 0 } = {}) => { … };
  ```

  This keeps the library agnostic to how three arrives (vendor file in the
  bench, blob-URL module inside the bundle) and makes the import surface
  explicit and testable.

## API rules

1. **Options objects, not positional params.** Every tunable has a default;
   a node called with no options must render something sensible.
2. **Nodes never own uniforms.** Callers create uniforms and pass them in as
   option values. The library exports helpers (e.g. `makeFlux(TSL)`) that
   *return* uniforms for the caller to hold.
3. **Nodes never bake `time`.** Anything animated takes a clock node option
   (default may fall back to `TSL.time`, but a caller-supplied flux-scaled
   clock — `time.mul(uFlux.mul(1.8).add(0.25))` — must pass through cleanly).
4. **MaterialX isolation.** Only `src/noise/adapters/mx.js` may reference
   `mx_*` symbols, always feature-detected. Everything else consumes the
   library interfaces (`fbm`, `worleyF1`, `gradientNoise`, `valueNoise`),
   which guarantee a pure-TSL fallback.
5. **Derived display source.** Each node module exports `source()` returning
   the curated, readable TSL snippet shown in the Lab. It lives in the same
   file as the implementation and changes in the same commit. Registry
   validation rejects display text that does not come from the module.
6. **Known-constraint clamps live inside the node.** e.g. the fire ramp
   clamps its input to ≤ 0.95 internally (above it the b/b²/b⁴ channel
   ordering inverts and plasma turns blue-white) — callers cannot hit the
   trap.

## Naming

- Files and exports: camelCase (`radialPulse.js` exports `radialPulse`).
- Uniform-returning helpers: `make<Thing>`.
- Option names match the hero/Lab vocabulary where one exists
  (`octaves`, `lacunarity`, `gain`, `power`, `freq`, `speed`).

## Color

- All math in linear space; the renderer's default output transform handles
  display. Nodes emit linear color and document it.
- Brand colors come only from `src/util/palette.js` (cyan `#57D4FF`, blue
  `#2B6CF6`, ice `#EAF7FF`, gold `#F4C95D`, ember `#FF7A1A`, void `#0A0E14`,
  silver `#98A8BE`, slate `#1E2836`, mist `#9AA7BC`) — never hex literals in
  node or material code.

## Doc block

Every node file opens with:

```js
/**
 * <name> — one-line description.
 *
 * @param  {object} opts
 * @param  {number} [opts.power=3]   … (range noted)
 * @returns {Node} float | vec3 …
 * @cost    class ② — see docs/COST-METHOD.md; measured numbers in REGISTRY.json
 * @backend wgsl ✓ / glsl ✓ — caveats here (e.g. fallback-only on …)
 */
```

## Registry

`docs/REGISTRY.json` is the single source of truth. Per node:

```json
{
  "noise/fbm": {
    "status": "verified",
    "impl": { "webgpu": "native", "webgl2": "native" },
    "parity": "pass",
    "cost": { "gpuMs": 0.82, "wallMs": 1.11, "costClass": 2 },
    "baseline": { "gpu": "…", "browser": "…", "os": "…", "three": "r178" },
    "verified": "2026-07-27"
  }
}
```

`NODES.md`, Lab badges, and the node gallery are generated from the registry.
Nothing the registry can generate is hand-edited. Cost class (①–⑤) is the
public-facing metric; raw ms are provenance.
